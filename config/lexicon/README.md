# 關鍵詞表（規格 §8.2）

一詞一行，`#` 開頭為註解，程式啟動時載入。**可由業務人員直接維護，不需改程式碼。**

| 檔案 | 用途 | 命中後行為 |
| --- | --- | --- |
| `spam.txt` | 廣告／導流用語 | 配合 URL 樣式判定為 `spam`，可設定跳過 LLM |
| `self_harm.txt` | 自傷／自殺意念 | **強制送 LLM 覆核**並提升優先序；不得僅靠規則否定 |
| `political.txt` | 政治人物、政黨、選舉用語 | 標記 `politics`（中性資訊標記，見規格 §5.5） |

> 關鍵詞只是「提高注意」的前篩，最終判定一律由 LLM 依語境決定並經人工複核。
